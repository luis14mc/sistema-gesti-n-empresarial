# Capturas — Compras vistas separadas

Adjuntar en el PR tres capturas (desktop):

1. `/compras/borradores` — lista de borradores con acciones visibles.
2. `/compras/ordenes` — órdenes generadas con botones Ver / Descargar / Imprimir.
3. Detalle `/compras/ordenes/[id]` — barra sticky de acciones + visor PDF embebido.

Generar con usuario PROCUREMENT o ADMINISTRACION en entorno local (`pnpm dev`).
