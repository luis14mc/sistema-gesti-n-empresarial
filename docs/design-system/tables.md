# Tables

Application lists will migrate to one shared data-table frame in Phase 2C. Each table must support loading, empty, and error states, controlled horizontal scrolling, search or filters where relevant, and pagination.

The primary row interaction opens detail and must work with pointer, Enter, and Space. Secondary actions belong in one labeled three-dot menu. Destructive actions require confirmation. Do not place multiple unlabeled icon actions in every row.

Table headers use semantic `<th>` elements. Interactive controls require accessible names; color alone cannot communicate status.
