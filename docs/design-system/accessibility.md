# Accessibility

The target is WCAG 2.2 AA.

- Root language is Spanish.
- Keyboard focus uses a visible two-pixel primary outline.
- A skip link bypasses application navigation.
- Dialogs require titles and managed focus.
- Icon-only actions require Spanish accessible names.
- Status combines text with color.
- Dynamic loading uses polite status announcements; errors use alerts.
- Interactive targets must be at least 24 by 24 CSS pixels.
- Layout must remain usable at 200% zoom and at 360px width.
- Reduced-motion preferences are respected globally.

Automated tests supplement but do not replace keyboard, screen-reader, zoom, contrast, mobile, and dark-mode verification.
