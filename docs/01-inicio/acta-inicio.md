# Acta de Inicio del Proyecto (Project Charter)

## 1. Objetivo
Aprobar formalmente el inicio del proyecto "Sistema de Gestión Empresarial" y autorizar la asignación de recursos para su desarrollo y ejecución.

## 2. Alcance General
El sistema automatizará y centralizará la gestión de: tickets de soporte técnico, oficios/documentos formales, inventario de equipos y su asignación, control de asistencia (entradas de tiempo) y control de usuarios bajo un esquema de roles estrictos.

## 3. Responsables
| Rol | Responsabilidad | Responsable Asignado |
|---|---|---|
| **Patrocinador** | Aprobación de presupuesto y liberaciones | N/A |
| **Director de Proyecto** | Gestión, tiempos y recursos | N/A |
| **Arquitecto de Software** | Diseño técnico, seguridad (ISO 27001) | N/A |
| **Líder QA** | Aseguramiento de Calidad (ISO 25010) | N/A |

## 4. Descripción y Justificación
La organización carece de una herramienta unificada para la gestión operativa, lo que genera retrasos y pérdida de trazabilidad. Este sistema resolverá el problema centralizando la operación bajo una plataforma web moderna, segura y auditable.

## 5. Criterios de Aceptación Preliminares
- Cumplimiento de la norma ISO/IEC 27001 en el manejo de datos.
- Operatividad en la nube al 99.9% de uptime.
- Tiempos de respuesta (Latency) en interfaz menores a 200ms.
